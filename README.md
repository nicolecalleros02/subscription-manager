# Subscription Manager

A subscription management application that tracks expenses, monitors billing cycles, and provides renewal reminders.

## Features
* User authentication (Sign Up/Log in)
* Dashboard with total monthly expenses and list of subscriptions
* Add, delete, and edit subscriptions
* Calendar view with a view of upcoming renewals
